## this repo includes the llm and rag based chatbots and experiments

## rag based chatbots
1. document-chatbot
- user enters the documents/notes & a query
- the application performs loading, chunking, embeddings storing vectos
- and in turn it returns related sentences or paragraphs as answers(update it with a real contextual answers based on the query and notes)

2. github-qna-chatbot
- user enters a public based repo and/or a query
- chatbot reads and performs llm and rag based operations
- in return the chatbot answers the query or summarizes the repo

3. research-assistant-chatbot
- user enters a research paper/topic and/or a query
- chatbot gathers information via different sources(websites, etc)
- chatbots answers the users query with proper context
