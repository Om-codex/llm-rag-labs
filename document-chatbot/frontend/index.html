What it does

Answers you can trace back to the page

This is a focused RAG application, not a general chatbot. It reads your documents, retrieves the passages that matter, and answers from that context only.

Grounded by design

The prompt instructs the model to use only the retrieved context. If the answer is not there, it says so instead of guessing.

PDF, TXT, DOCX — and pasted text

PyPDF, Docx2txt and plain-text loaders feed one ingestion pipeline. Pasted notes are chunked and embedded the same way.

Local embeddings

Chunks are embedded on your machine with all-MiniLM-L6-v2 (384 dimensions). No embedding API key, no per-chunk cost.

Sources with every answer

Each response lists the retrieved chunks with filename, chunk index and page metadata when the loader provides it.

Scoped retrieval

Search the whole library or tick specific documents, and choose how many chunks to retrieve (1–20) for each question.

A library that survives restarts

ChromaDB persists vectors to local disk. Content-based SHA-256 IDs make re-uploading the same file safe rather than duplicated.
